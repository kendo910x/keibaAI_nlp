[前回研究](2026-11-26_nlp_collection_routes_horse_seeds_report.md)の451 URL・452版、馬名一覧、本文の直接保存、再開機構は再利用する。一方、新規426 URLはnetkeiba 334、個人の回顧等75、JRA17に集中しており、主要媒体を広く探す基礎調査の完了を示すものではなかった。「次は常用化だけ」としたレビューの優先順位を訂正した。

広いWeb検索と公式ページの確認では、スポーツナビの複数媒体の配信一覧、スポニチとデイリーの新着・調教記事、日刊スポーツの一覧と過去記事、ウマニティの2021年ジャパンC特集・当時の談話、ラジオNIKKEIの月別一覧・調教師談話へ到達した。[媒体別の入口と確認範囲](../../../skills/keiba-search/references/media-discovery.md)に出典を残した。東スポの一覧は今回のWeb抽出で本文欄が出ず、馬トク・サンスポ・競馬ラボ・競馬ブックには取得ツールの拒否があった。これを媒体全体の記事不在や恒久的な除外理由とは扱わない。

今回の閲覧は基礎確認であり、研究用コーパスの追加保存や大量巡回、VMでの再現試験は行っていない。451 URL・452版を今回再集計したものでもない。

## 変更内容

- `poc/search_research/routes.py`：robots取得、解析、複数User-Agentの合成拒否、robots取得失敗を理由とする再試行分岐を除去。HTTP本文取得とブラウザー表示前の両方から事前ゲートを外した。
- `poc/search_research/research.py`：旧 `capture` 経路にもあったrobots事前取得・拒否を除去。URL形式と別のmetadata-only設定の確認は残した。
- 研究用requirementsから使用しなくなったProtegoを除去。HTTPのUser-Agentは変更していない。
- 通常の1秒間隔、公開URL検証、実HTTPエラー、401/403時の当該バッチ中断、429/503時の再開位置とRetry-Afterの返却、公開部分の保存を維持した。外部の共用取得サービスやWebツール自身の制約を変更していない。
- AGENTS、README、実行環境用AGENTS、検索・統括Skillへ、主要媒体の基礎調査続行、Local LLMの数日〜1週間程度の初期処理許容、記事が見つからない馬を深追いしないこと、robots独自ゲート撤廃を反映した。
- [次の研究指示](../../instructions/2026-11/2026-11-26_nlp_major_media_discovery_instruction.md)を追加。既存の動的一覧MCPを再利用し、必要なフォーム操作等は既存のブラウザー手段も候補にする。ブラウザーの新設・VM配備が済んだとは扱わない。

`research.links_only()` のスポニチ・競馬ラボの固定設定、およびGit外の `collection-policy.json` はrobotsとは別機構である。この変更では削除していない。主要媒体の保存状況を調べる際は、その根拠・適用範囲と実際のアクセス結果を区別する。

## 検証

実サイトへ負荷をかけないモック応答を使い、変更した取得経路をPythonで実行した。

| 確認 | 結果 |
|---|---|
| 研究モジュール3本のPython構文 | 解析成功 |
| 直接URLからの本文保存 | robotsへの通信なしで本文を保存 |
| 追跡パラメーターだけ違う既知URL | 既存取得IDを再利用し、追加通信なし |
| HTTP 429 | バッチ中断、同じ候補のoffsetとRetry-Afterを保持 |
| HTTP 403 | エラーを記録し、そのバッチの次候補へ進まない |
| private IPへのredirect | private宛ての通信前に拒否 |
| 旧shared capture | robotsの事前HTTP通信なしで共用取得結果を保存 |
| 別のURL形式・metadata-only判定 | 従来の判定を維持 |

実機のVM・通常DB・Local LLM・共有MCPには変更を配備していない。研究プロファイルへ反映する際は、コードとSkillに加え、Git外へ複製した古い `work-rules.md` を更新する。既存の研究データを消したり取得し直したりする必要はない。
